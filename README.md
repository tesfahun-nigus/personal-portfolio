# Tesfahun Nigus Portfolio

## Description

A personal portfolio website built with semantic HTML5 to introduce my background, education, learning journey, technical interests, projects, goals, and contact information.

This project focuses on building a well-structured, accessible, and organized multi-page website while practicing HTML fundamentals, semantic HTML, navigation, relative file paths, images, and Git version control.

## Features

- Multi-page portfolio website
- Semantic HTML5 structure
- Consistent navigation across pages
- Accessible images with meaningful `alt` text
- Internal navigation between pages
- Contact information with email and GitHub links
- Project descriptions and demonstrated skills
- Short-term, medium-term, and long-term goals
- Organized project folder structure
